# Enterprise-Campus-Network-Design-using-Cisco-Packet-Tracer

Enterprise Campus Network Design using Cisco Packet Tracer

• Planned and implemented a scalable enterprise network connecting 2 campuses, 10 VLANs, 30+ hosts, 3 routers, and multiple switches, ensuring end-to-end connectivity across all departments.

• Configured RIP routing across 2 campuses, 10 VLANs, and trunk links to support communication between 30+ hosts.

• Deployed 5 network services (DHCP, DNS, HTTP, FTP, and Email) supporting automated IP allocation and centralized resource access and automated IP address allocation.

• Designed IP addressing schemes for 10 VLANs and 30+ hosts, improving network scalability and address utilization to optimize IP utilization, scalability, and network performance.

• Implemented trunk links between switches to support VLAN communication across departments.

• Simulated FTP, Email, DNS, and Web services to support enterprise resource sharing and communication.

• Conducted 20+ ICMP connectivity tests using ping commands to verify end-to-end communication between VLANs, routers, servers, and remote campus locations, ensuring reliable network connectivity.
